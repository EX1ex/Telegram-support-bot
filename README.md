# Telegram-support-bot

بوت تكت للتيليجرام
طريقة الاستخدام:

١- استبدل bot_token بتوكن بوتك في تيليجرام

٢- انشئ قروب تيليجرام و فعّل فيه خاصيه الاقسام و انسخ id القروب

٣- ضع id القروب في group id 

٤- شغل البوت على اي استضافه

عند دخول الشخص يرسل start للتواصل مع الدعم، البوت سينشئ قسم خاص بهذا الشخص يمكنك التراسل معه داخل هذا القسم و ينشئ قسم مختلف لكل عضو جديد
 لحذف التكت ارسل /close في القروب داخل القسم المراد حذفه
